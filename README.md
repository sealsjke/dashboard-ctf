# OmCTF Live Analytics

Панель статистики академического зачёта OmCTF: эфир атак, круговая диаграмма долей атакующих команд, история по раундам, матрица атак, состояние сервисов и таблица команд. Данные берутся из публичных API [официальной борды](https://board-academy.ad.omctf.ru/). Сервер опрашивает их раз в 5 секунд и передаёт обновления браузеру через Server-Sent Events.

Ссылки в панели ведут на [общую визуализацию соревнования](https://visual-academy.ad.omctf.ru/) и отдельную [визуализацию задачи «Казна»](https://board-academy.ad.omctf.ru/arena/treasury/visual/).

## Запуск

```sh
docker compose up --build -d
```

Открыть <http://localhost:3000>. Вход: `smd` / `kapusta666`. Порт, источник и учётные данные можно изменить через `PORT`, `SOURCE_URL`, `AUTH_USER`, `AUTH_PASSWORD` в окружении `docker compose`. Например:

```sh
PORT=8080 SOURCE_URL=https://board-academy.ad.omctf.ru docker compose up --build -d
```

Для запуска без Docker нужен Node.js 20 или новее: `npm start`.

Источник публикует агрегированную историю атак по раундам. Лента показывает последние записи этой истории; отдельные захваты внутри одной записи не восстанавливаются. API ограничивает ответ 5000 записями, поэтому при большом числе атак начало 30-раундного графика может быть неполным. Если источник временно недоступен, панель сохраняет последний полученный срез и показывает предупреждение.
